# Gravações do portfólio

Coloque aqui os vídeos (.mp4) das gravações de tela dos sites entregues. O nome
do arquivo deve ser o `slug` do projeto definido em `src/data.js`:

- `vetra.mp4` — Vetra Engenharia
- `aurum.mp4` — Clínica Aurum
- `mosaico.mp4` — Mosaico Arquitetura
- `forja.mp4` — Forja Performance
- `lume.mp4` — Lume Odontologia
- `atlas.mp4` — Atlas Logística

Recomendações: H.264/MP4, ~1920×1080 (ou 16:9), 8–20s em loop, sem áudio (o
player inicia mudo), comprimido (alvo < 6 MB cada). A seção interna do projeto
toca o vídeo automaticamente; enquanto o arquivo não existir, mostra a imagem.
